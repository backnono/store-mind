# Customer Miniapp — 验收清单

> 目标：确认前端 小王 数字店员体验在微信开发者工具中可正常运行。

## 前置条件

- [ ] `cd frontend && npm install` 成功
- [ ] `npm run build:weapp` 无报错
- [ ] `npm run typecheck` 通过
- [ ] `npm test` 全部通过
- [ ] 微信开发者工具已打开 `frontend/dist`

## 功能验收

### 门店首页

- [ ] 门店首页加载，显示门店名称（阳光便利店 No.3）和地址
- [ ] 小王问候卡片显示：头像"王"、在线状态绿灯、欢迎文案
- [ ] 点击「问小王」跳转到聊天页，入口为 `first_open`
- [ ] 今日推荐列表渲染 3 条（促销、新品、热销）
- [ ] 点击推荐条目跳转到聊天页，入口为 `promo` 或 `product_detail`
- [ ] 扫码按钮存在

### 聊天页 — first_open

- [ ] 聊天页显示头部"小王 · 数字店员"，在线状态
- [ ] 首条助理消息渲染破冰文案
- [ ] 破冰消息下渲染 4 个引导问题芯片（薯片/活动/低糖/付款）
- [ ] 点击引导芯片 → 输入框填充文案，不自动发送

### 聊天页 — zone_scan

- [ ] 模拟 zone_scan 入口，顶部显示货架区域 Banner
- [ ] 助理消息渲染（或 fallback 文案）

### 发送消息

- [ ] 输入文字后点击发送 → 用户消息立即渲染，助理占位渲染 thinking dots
- [ ] 助理回复渲染，带反馈按钮
- [ ] draftText 清空

### 反馈

- [ ] 助理消息显示 👍 👎 反馈按钮
- [ ] 点击 👍 后状态锁定为 👍，不可重复提交
- [ ] 用户消息不显示反馈按钮

### 异常状态

- [ ] 模拟网络失败 → 用户消息显示"发送失败"，可点击重试
- [ ] 后端超时 → 收到"请求超时"提示

### 持久化

- [ ] 发送消息后退出聊天页再进入 → session_id 被保留
- [ ] 最近 20 条消息恢复

## 视觉验收

- [ ] 页面背景为暗色 `#1c1b18`
- [ ] 消息气泡区分用户（右侧深灰色）和助理（左侧暗棕色）
- [ ] 品牌暖色 `#c9863a` 出现在关键交互元素上
- [ ] 文案可读，移动端字号合适
- [ ] 引导芯片和反馈按钮可点击区域足够大

## 后端验证

- [ ] `cd backend && python3 scripts/validate.py` 通过，前端改动不影响后端

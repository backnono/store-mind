# DESIGN.md — 无人超市数字店员 Agent

## Scene
顾客站在无人超市货架间，手持手机，周围是琳琅满目的商品货架。灯光明亮均匀（超市照明），环境偏嘈杂。用户需要快速找到信息，注意力分散于手机屏幕和货架之间。

→ **设计方向**：高对比度、大字号、信息层级清晰、一眼可扫。暗色背景模仿店员在耳边轻声指引的感觉，不抢超市环境的注意力。

## Color Strategy: Restrained
- 暗色主基调，模拟"耳边轻语"的私密服务感
- 一个品牌暖色作为交互强调色（店员制服色）
- 中性色向暖色调微偏，避免冷冰冰的科技感

## Typography
- 中文优先，系统原生中文字体
- 对话气泡清晰可辨，字号够大（移动端阅读距离）
- 库存可信度用色彩+文案双重编码

## Components
- 对话气泡：顾客与店员对话流
- 商品卡片：嵌入对话中的结构化信息
- 可信度指示器：🟢🟡🟠🔴 四级可信度
- 引导建议按钮：Agent主动提出的追问/推荐

## Motion
- 新消息进入：从下淡入，模拟对话自然流
- 商品卡片：轻微缩放 + 阴影变化
- 不弹跳、不弹动

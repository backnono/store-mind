产品结构说明

  • 底部 Tab 栏：首页 | 购物 | 小王 | 订单 | 我的
    → 五个 Tab，用户只需记住「小王」就是聊天入口
  • 首页 → 小王：点击「问小王」或今日推荐，进入对话窗
  • 小王聊天窗：系统根据进入方式自动适配初始状态，用户只需开口问

首页入口 三种方式进入小王

  • 点击「问小王」 → 空对话窗，主动破冰 + 预设问题
  • 点击推荐商品 → 对话窗，自动带入该商品上下文
  • 点击活动卡片 → 对话窗，自动展开活动详情

货架入口 扫码直入

  • 扫货架 QR 码 → 对话窗，顶部显示当前区域，自动列出货架商品
  • 用户无需选择模式，zone 上下文由 QR 参数自动携带

系统自动处理的三种初始状态

  • 首次打开：无上下文 → 主动破冰
  • 货架扫码：有 zone_id → 展示当前货架商品
  • 恢复对话：有历史会话 → Context Bridge 回顾
